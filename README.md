# Brush Settings: reject unavailable tips without changing working selection

Follow-up in existing [PR #5338](https://github.com/storytold/photocraft/pull/5338). Before source: ae5f013108849df5e8ba67c1fe48e6a799dd8409; after source: 495e38d0fa57b642801b92c1aff825d04f121d9a.

Previously tools.setBrush applied preset identity and captured foreground before loading its bitmap resources. A resource error kept the old brush but leaked the new identity and colour. The Brush Settings primary grid also recorded identity before submitting its tip edit, enabling Update after a rejected selection. Load resources before engine metadata mutations; submit the grid's brush edit before recording identity and render its footer from accepted state. An unchanged look-alike remains selectable with an identity-only command.

Two new regressions fail at the previous head and pass after the fix. The engine test covers primary, dual and texture resources with/without a previous current preset and with/without captured colour (12 combinations), preserving brush/identity/colours/revisions/gesture/library/journal/saved brush on failure, then accepting a warmed-resource retry. The UI test covers fourteen themes with/without a previous current preset, rejected selection and Update availability, then a successful retry. The existing selection test also verifies unchanged look-alikes, accepted brush-before-identity order, Capture Size choices, minimal patches and replay. The original eight grid regressions remain in the full suite.

Full engine and UI + HEIF/examples/doctests: 4574 passed, zero failed, 31 ignored across 83 test binaries/doc groups. Strict all-target Clippy (-D warnings), fmt, layers, wasm, parity generation and the ignored panic_hunt suite passed. Test totals include pre-existing tests; this follow-up adds two tests.

Twelve native full-app egui/wgpu captures were inspected: primary grid and normal Brushes tab, Medium and Light, previous current/none, a 2x grid case, and a valid-tip control. The driver uses an original synthetic StoredTile preview with no attached preset store, so resource loading returns the real no-store error. It does not import a real broken ABR, repair bitmap files, or test a corrupt store. Both source revisions use the identical fixture/driver. Failed grid selection journals one identity command before and zero after; failed normal selection leaks red foreground before and preserves green after. After the fix every failed case preserves its original identity, brush, colours, revisions and preferences, and the UI keeps its original Update availability. Each case then selects successfully when its synthetic resource is made available. The accepted control images are pixel-identical; only their command order changes (brush before identity). JSON records state and image hashes. After capture, test-only unreachable branches were replaced with Option assertions for strict Clippy; all production and UI source remained byte-identical, as recorded in visual-summary.json.
